## Discoveries

- [KGTK](https://kgtk.readthedocs.io/en/latest/) - KGTK is a Python library for easy manipulation with knowledge graphs.
  - I'm interested in exchanging data between SQL, neo4j, and wikidata.
- [`tetro-tui`](https://github.com/Strophox/tetro-tui) - A Tetris clone as a TUI crate.
- [`ncdu`](https://dev.yorhel.nl/ncdu) - An Ncurses powered `du`-like tool.
- [OpenITCOCKPIT](https://openitcockpit.io/) - Pretty interface for monitoring IT resources.
  - This popped up on Reddit because of patch management.
  - It also caught my eye because its github pages showed event correlations.
- [The AI Vampire](https://steve-yegge.medium.com/the-ai-vampire-eda6e4f07163) - Article worth remembering.
- [Containers Don't Exist](https://www.youtube.com/watch?v=DUgzXX2_aDQ) - Great video on a topic I've been preaching for years: Containers are a function of the Linux kernel, not K8s and Docker.
