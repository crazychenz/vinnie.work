## Upgrading From Ubuntu 25.10 to Ubuntu 26.04

```
sudo apt update
sudo apt full-upgrade
sudo reboot

# Note: `-d` is because we're installed before release.
pkexec do-release-upgrade -d -f DistUpgradeViewKDE
# OR: sudo do-release-upgrade -d

lsb_release -a
```
