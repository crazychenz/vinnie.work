## Container Terms

- **OCI** - Open Container Initiative [[Wiki](https://en.wikipedia.org/wiki/Open_Container_Initiative)] [[Github](https://github.com/opencontainers)]
  - **runc** - OCI reference implmentation container runtime
- **CRE** - Container Runtime Engine - Parent process for containers and its namespaces.
- [**Linux Namespaces**](https://en.wikipedia.org/wiki/Linux_namespaces) - Partitioning of resources in kernel. (Fundamental to containerization!)
  - **Container** - A tree of processes that have been launched within a set of linux namespaces via the clone() syscall.
- **Docker** - Container Orchestration
- **Kubernetes** - Container Orchestration
  - **CRI** - Container Runtime Interface [[Docs](https://kubernetes.io/docs/concepts/architecture/cri/)]
  - **etcd** - key-value store
  - **kubelet** - per node k8s management agent
  - **pod** - scheduling unit in k8s ... also a single _network_ namespace
